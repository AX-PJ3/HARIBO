# team-wiki

우리 팀이 함께 지키는 **기준**을 모아 둔 팀 위키예요. 사람과 각자의 Claude Code가 모두 읽어요.
10/12부터 v0 도그푸딩으로 쓰고, 10/14쯤 진짜 도구(데이터베이스 + MCP)로 옮겨요.

## 처음 보는 사람은

1. `INDEX.md`를 열어요. 항상 적용되는 기준과 영역 목록이 있어요.
2. 기준을 새로 쓰거나 고치기 전에 `기준-작성-원칙.md`를 읽어요.
3. 기준을 바꾸면 버전을 1 올리고 `CHANGELOG.md` 맨 아래에 한 줄 남겨요.
4. 고친 뒤에는 형식 검사를 돌려요.

```bash
python3 team-wiki/scripts/check_wiki.py team-wiki
```

## 각자 CLAUDE.md에 붙여 넣을 규칙

```markdown
## 팀 위키 규칙
- 팀 위키 위치: <HARIBO 저장소 경로>/team-wiki
- 작업을 시작하기 전에 팀 위키의 INDEX.md를 읽는다. "항상 적용되는 기준"은 모든 작업에서 지킨다.
- 이번 작업과 관련된 영역 파일만 열어 본다. 위키 전체를 읽지 않는다.
- 팀 위키에 있는 기준과 다르게 만들게 되면, 만들기 전에 사용자에게 "팀 기준을 바꾸는 건지" 먼저 묻는다.
- 기준을 바꾸기로 하면: 해당 기준의 값·이유·근거를 고치고 버전을 1 올린 뒤, CHANGELOG.md 맨 아래에 한 줄을 남긴다.
  형식: 날짜 시각 | 누가 | 기준 ID 이전→새 버전 | 이전 값 → 새 값 | 이유 | 출처(코드/AI 대화/Figma/회의/Slack)
- 관련 기준이 없어서 새로 정했다면 기준-작성-원칙.md대로 새 기준을 추가하고 CHANGELOG에 남긴다.
- `잠금: 예`인 기준은 고치지 않고 사용자에게 알린다.
- 기준은 지우지 않는다. 쓰지 않게 되면 상태를 폐기로 바꾸고 대체 ID를 적는다.
- 위키를 고친 뒤 `python3 team-wiki/scripts/check_wiki.py team-wiki`를 실행해 오류가 없는지 확인한다.
```
